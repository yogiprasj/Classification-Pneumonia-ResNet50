# Classification Pneumonia using ResNet50

This project presents a deep learning-based system for early detection of pneumonia using chest X-ray images. The model is built using the ResNet50 architecture and deployed as a web-based prototype for decision support.

---

## Overview

Pneumonia is a respiratory disease that requires timely and accurate detection. This project implements a Convolutional Neural Network (CNN) based on ResNet50 to classify chest X-ray images into two categories:

* NORMAL
* PNEUMONIA

The system is designed as a decision support tool to assist in early screening, not as a replacement for clinical diagnosis.

---

## Methodology

### Model Architecture

* ResNet50 pretrained on ImageNet
* Transfer learning approach
* Fine-tuning on final layers

### Data Processing

* Image resizing to 224x224
* Pixel normalization (0–1 scaling)
* Data augmentation:

  * Rotation
  * Zoom
  * Horizontal flip

### Training Strategy

* Two-phase training:

  1. Freeze base model
  2. Fine-tune selected layers

### Evaluation Metrics

* Accuracy
* Precision
* Recall (Sensitivity)
* F1-Score
* Confusion Matrix
* ROC Curve and AUC

---

## Threshold Optimization

Instead of using the default classification threshold (0.5), this project applies threshold tuning based on experimental analysis.

Thresholds were evaluated in the range:

0.05 to 0.95 (step size 0.05)

The optimal threshold was selected using:

* ROC Curve analysis
* Youden Index

### Key Result

* Optimal threshold: 0.1
* High recall (~97%)
* Minimal false negatives

This approach prioritizes sensitivity, which is critical in medical screening to reduce missed cases.
